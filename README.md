# Neptune

An all-in-one, self-hosted tool for college students. Keep tabs on your courses, assignments, and more!

![app example image](/public/app_example.png)

Made for Hack Club's [Stardance](https://stardance.hackclub.com/projects/31684)!

## Features

- See and manage all your courses
- Create and manage tasks, with smart due date recognition from the title
- Smart overview for your whole day
- Easy to use calendar
	- Shows all courses and tasks
	- 2-way syncing with your favorite calendar apps! (Neptune courses on other calendars, your events on Neptune calendar)
- Study tools
	- Customizable pomodoro timer
	- Flashcards
